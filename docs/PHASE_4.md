# Phase 4 — базовые потребности

Статус: начат. Phase 3 завершён. Реализован только голод; питание, места еды, новые намерения и последствия отсутствуют.

ResidentData.hunger остаётся целым числом 0–100; setter ограничивает диапазон. Main/ResidentHunger (scripts/resident_hunger.gd) получает данные и слушает GameTime.minute_changed. Каждый сигнал означает одну прошедшую игровую минуту, включая каждую минуту длинного кадра и debug-перемотки.

Темп прототипа: бодрствование (IDLE/MOVING/WORKING) +1 за 15 игровых минут; SLEEPING +1 за 60 минут. Остаток хранится в целых долях в ResidentHunger, сохраняется между занятиями; на верхней границе сбрасывается. Нет зависимости от кадров, изображения, карточки или выбора. Карточка читает актуальные данные как раньше.

На x1/x2/x4 рост за одинаковое игровое время одинаков; в реальных секундах ускоряется вместе с часами. На обычной паузе роста нет. F6/F7/F8 явно двигают игровое время даже на паузе — голод растёт соответственно текущему занятию на каждой минуте. Перемотка не симулирует движение; сон начинается только при реальном прибытии домой. Последняя минута перед сменой фазы относится к прежнему занятию.

F9 добавляет 25 голода выбранному жителю, максимум 100; работает на паузе и любой скорости, без продвижения часов. Без выбора ничего не делает. Удержание не повторяет добавление. Подсказка находится в HUD. Это только инструмент разработки.

Голод не меняет решения: при 100 Степан продолжает ходить на работу и домой. WORKING ничего не производит, сон не восстанавливает усталость. Fatigue=35 и mood=65 сохраняются. Здания, еда, новые занятия/намерения не добавлены.

Проверка: F5 → выбрать Степана, старт 20. На x1 спустя 15 игровых минут будет 21; x2 — примерно 7,5 реальных секунд, x4 — 3,75. Пауза без debug: значение стоит. F9: +25, после нескольких нажатий ровно 100. Закрыть карточку → F9 не меняет данные. F8 до 23:00, дождаться «Спит»; записать голод ниже 100, F6 добавит 1 за час сна (насыщенный голод уже не растёт). Для сравнения вне сна час добавляет 4. При 100 проверить полный цикл F8: работа и сон сохраняются.
